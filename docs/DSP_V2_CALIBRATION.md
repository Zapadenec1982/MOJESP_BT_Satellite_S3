# Калібрування стелі підсилювача (DSP v2)

> **18.10.2026: сторінки цього калібрування у вебінтерфейсі більше немає.** Замовник: межу
> гучності людина ставить одним регулятором — «Максимум» у «Звуку»; сторінка з мультиметром,
> пошуком на слух і перевіркою живлення — зайва. C лишається тим, що дає даташит (−9,8 dBFS,
> `audio.amp_clip_db10` = −98, лімітер на −10,3), або тим, що вже записано; змінити його можна
> лише через API (`POST /api/settings {"audio.amp_clip_db10": …}`). «Драйв» і «Стеля потужності
> басу» прибрано з тієї самої причини. Процедура нижче лишається довідкою для того, хто міряє
> модуль на стенді.

Навіщо. Усередині DSP 1,0 — це найгучніше, що підсилювач відтворює чисто («стеля» C), а не
повна шкала ЦАП. Лімітер стоїть на 0,5 дБ нижче C, тому підсилювач не кліпує і не йде в захист.
Типове C = −9,8 dBFS виведене з даташиту TPA3255 при PVDD 24 В (SLASEA8A §7.5): воно правильне
для двох поширених схем входу модуля, але не для всіх. Поки C не виміряне, максимум може бути
тихішим, ніж дозволяє ваш модуль (якщо C насправді вище), або підсилювач ще кліпуватиме (якщо
модуль має додаткове підсилення на вході). Калібрування займає ~10 хвилин.

Потрібно: мультиметр із режимом AC V, бажано телефон із застосунком-спектроаналізатором.

Усе робиться з телефона, у вебінтерфейсі панелі: **Система › Сервіс › Калібрування**, завдання
**Стеля підсилювача** (з 12.10.2026, етап W5). Кроки там ті самі, що нижче, і кожен має кнопку
«Встановити», яка сама ставить потрібний тон; виміряні вольти вписуються в поля, стеля C
рахується сама. Те саме можна задати запитом:

```
curl -X POST http://<panel>/api/settings -d "{\"audio.tone_mode\": 1}"
```

> Калібрувальний тон іде **повз** DSP і гучність, точно на заданому рівні ЦАП. Він вимикається
> сам через 60 с (джерело → «Вимкнено»). Кроки 3–4 гучні (до десятків ват) — коротко, без
> навушників, колонки на місці.

## Кроки

**0. PVDD у спокої.** Мультиметр (DC V) на клеми живлення підсилювача. Записати, напр. 24,1 В.

**1. Тон −26 dBFS, лівий канал.**
Джерело = «Тест-тон»; «Тон» = «Калібрування: точний рівень ЦАП»; частота тону = 60;
рівень = −260 (десяті dBFS, тобто −26 dBFS); канал = «Лівий».
Мультиметр (AC V) **між двома клемами лівої колонки** (жодну не на землю — це BTL). Записати V.

**2. Як увімкнений вхід модуля.** Той самий тон. AC V від **кожної** клеми лівої колонки до
землі підсилювача (мінус живлення):
- обидві ≈ V/2 — гойдаються обидва напівмости: `Vmax = 0,95 × PVDD`;
- одна ≈ V, друга ≈ 0 — гойдається один напівміст: `Vmax = 0,95 × PVDD / 2`
  (модуль подає несиметричний сигнал на один вхід; потужність — чверть можливої, це питання
  заліза, не прошивки).

Стеля: `C = −26 + 20·log10( Vmax / (1,414 × V) )`.
Повторити 1–2 для правого каналу (канал = «Правий»); взяти **менше** з двох C.

Приклад: PVDD 24 В, один напівміст → Vmax = 11,4 В; виміряно V = 1,25 В →
C = −26 + 20·log10(11,4 / 1,77) = −26 + 16,2 = **−9,8 dBFS**.

**3. Перевірка на слух.** «Тон» = «Калібрування: сплески 250/750 мс», частота 100, канал «Обидва».
Рівень по черзі `10 × (C − 1)` і `10 × (C + 1)` (напр. −108 і −88):
на C + 1 звук стає різким (у спектроаналізаторі телефона 3-тя гармоніка, 300 Гц, підскакує на
~20 dB) або світиться CLIP на модулі; на C − 1 — чисто.
- різко й на C − 1 → зменшити C на 0,5 і повторити;
- чисто й на C + 1 → збільшити C на 0,5 (максимум на 1,5 dB вище розрахунку).

**4. Блок живлення.** «Тон» = «Калібрування: точний рівень ЦАП», частота 60, канал «Обидва»,
рівень `10 × (C − 0,5)`, ~3 с, мультиметр (DC V) на PVDD:
- PVDD просідає більше ніж на 2 В, БЖ блимає або вимикається → блок живлення не тягне сталий
  бас: «Стеля потужності басу» (`audio.rms_cap_db10`) = −30; потім на звичайній музиці з
  важким басом на 100 % гучності знову глянути PVDD; якщо просідання ще > 2 В — ще −10 (−40).
- просідання менше → стелю потужності не вмикати, а C зменшити на `20·log10(PVDD під
  навантаженням / PVDD у спокої)` (напр. 23,2 / 24,1 → −0,3 dB).

**5. Записати.** «Стеля підсилювача» (`audio.amp_clip_db10`) = `round(10 × C)`, напр. −98;
«Звідки стеля» (`audio.amp_src`) = 3, «виміряно»; «Відкалібровано» (`audio.amp_cal`) = увімкнено.
«Тон» назад на «Через DSP», джерело — як було. «Поріг лімітера» (`audio.ceiling_dbfs`) покаже C − 0,5.

**Без мультиметра.** Лише крок 3: рівень наростає від −160 (−16 dBFS) кроком +5 (0,5 dB) до першої
різкості; C = цей рівень − 0,5 dB (точність ±1 dB). `audio.amp_src` = 2, «на слух»;
`audio.amp_cal` лишається вимкненим.

**Звідки стеля** (`audio.amp_src`, з 14.10.2026): 0 — з даташиту, 1 — вписано вручну, 2 — знайдено
на слух, 3 — виміряно. `audio.amp_cal` лишається для сумісності й означає лише «виміряно».
- Веб не дає записати «виміряно», доки немає обох каналів (кроки 0–2 для лівого й правого), і
  «на слух», доки не пролунав тон того рівня, який записується. Число, вписане чи поправлене
  вручну, — завжди «вписано вручну».
- Під час старту прошивка вирівнює ці ключі. Стеля, що не дорівнює даташитній, але позначена
  «з даташиту», стає «вписано вручну». Так переходять і модулі, відкалібровані до 14.10.2026:
  тоді «Записати» ставило «відкалібровано» будь-якому числу, навіть невиміряному.

## Частота порту колонок (Сервіс › Калібрування › «Частота порту колонок»)

Для колонок-фазоінверторів — з отвором-портом спереду чи ззаду (Denon SC-G101: порт ззаду). На
частоті порту повітря в ньому качає найбільше, а дифузор майже стоїть; нижче неї динамік уже
нічим не тримається. Знаючи цю частоту, панель ставить сабсонік трохи нижче неї і піднімає бас
саме на ній — там, де це майже нічого не коштує дифузору.

1. «Частота порту» (`audio.port_hz`) = 0, поки міряєте.
2. Джерело = «Тест-тон», «Тон» = «Через DSP», гучність ~20 %. Зняти решітку з однієї колонки.
3. Частоту тону від 30 до 80 Гц кроком 2–5 Гц. Дивитися на дифузор великого динаміка (або ледь
   торкнутися його пальцем) і тримати долоню біля порту. Частота, де дифузор майже не рухається,
   а з порту дме найсильніше, — шукана. Нижче ~40 Гц тон тихіший (сабсонік), на місце мінімуму це
   не впливає.
4. Записати її в «Частота порту». «Підйом біля порту» (`audio.port_lift_db`) лишити 3 дБ; гуде —
   2, мало басу — 4–5. «Сабсонік» поки задана частота порту не діє.

У вебі («Вручну» → «Встановити») кроки 1–2 робляться без запису (з 14.10.2026): порт вимкнено й
гучність не вище 20 % лише поки грає тон — ключі `audio.cal_port_off` і `audio.cal_vol_cap`
не зберігаються й зникають разом із тоном. Закрили сторінку посеред пошуку — збережені частота
порту й гучність ті самі. Тон через DSP вимикається сам через 2 хв без змін.

**Автоматично, мікрофоном панелі** (~45 с; там же, «Мікрофоном панелі»):

1. Мікрофон плати — біля верхнього краю панелі (`docs/PANEL.md`). Поставити панель так, щоб цей
   край був за 0,5–1 см від центру великого динаміка (пилозахисного ковпачка) однієї колонки, не
   торкаючись; решітку краще зняти. У кімнаті тиша.
2. «Яку колонку міряти» — ту, що біля панелі; «Виміряти» — увімкнути.
3. Панель ~4 с слухає тишу, потім колонка ~35 с грає тихі тони 20…100 Гц (повз DSP, на рівні, який
   панель підбирає сама, від −60 до −30 dBFS). Після цього джерело, тест-тон і його рівень
   повертаються як були. Вимкнути «Виміряти» посеред — перервати.
4. Стан виміру:
   - «готово: N Гц, виставлено» — провал чіткий з обох боків, частоту порту записано;
   - «сумнівно, ~N Гц: перевірте пальцем» — провал знайдено, але не записано: перевірити
     пальцем (нижче) і вписати самому. Так буде найчастіше: мікрофон панелі погано чує низ
     (~20 дБ/октаву нижче ~70 Гц), і підйом під провалом виходить малим;
   - «провалу нема» — колонка закрита (тоді частота порту не потрібна) або мікрофон далеко;
   - «мікрофон не чує тону» — панель не біля обраної колонки.

**Перевірка пальцем — остаточна.** Тон з телефона через Bluetooth (генератор тону), DSP на час
перевірки нейтральний («Частота порту» 0, «Тонкомпенсація» 0, DSP вимкнено), гучність помірна;
палець легенько на ковпачок у центрі великого динаміка; 55, 60, 65, 70, 75 Гц — де вібрація
найслабша, там частота порту. Мікрофон панелі може помилитися на кілька герц: резонанс кімнати на
частоті порту, який сам порт і розгойдує, заповнює провал і зсуває його (04.10.2026, Denon
SC-G101: панель — 67,7 Гц «впевнено», палець — 63 Гц; на 63 Гц підйом дав глибину, яку замовник
почув). Порт ззаду, навпаки, тягне провал донизу (на моделі — до 3 %). Уся крива виміру — у
консолі, рядками `port meter, dBFS tone/noise …`.

**Тонкомпенсація** (`audio.loudness`, типово 70 %; у вебі — Налаштування › «Тонке налаштування», на склі — перемикач у «Звуку»): на тихій гучності повертає бас і верхи, які
вухо там недочуває; на 100 % гучності її немає — або на «Звичайній гучності» (`audio.loud_ref`, там
само), якщо її задано. Скільки басу вона додає зараз — `audio.loud_db`.
Здається забагато — 40–50 %; замало — 90–100 %.

## Що дивитися потім (Сервіс, група «Аудіо»; кольори — за таблицею нижче)

| ключ | норма | якщо ні |
|---|---|---|
| `audio.lim_gr` | 0 на звичайній гучності; кілька dB на 100 % з гучним мастером | постійно > 3 dB — стоїть драйв або C завищене |
| `audio.bass_gr` | 0…6 dB на гучному басу на 100 % | > 10 dB постійно — бас-підйом EQ занадто великий для 24 В |
| `audio.out_clamps` | 0 | будь-що інше — помилка ланцюга, повідомити |
| `audio.dsp_faults` | 0 | будь-що інше — NaN/Inf у ланцюгу, повідомити з логом |
| `audio.dsp_pct` / `dsp_max_pct` | 192 кГц: до ~35 % / до ~80 % | більше — повідомити (є запас: рішення в дизайні §5) |

Інші налаштування — у вебі, Налаштування › «Тонке налаштування» (з 18.10.2026; до того — блок
«Для фахівців» на сторінці калібрування): **Сабсонік** (`audio.hp_hz`, типово 40 Гц; поки задано
порт, не діє — стоїть під портом сам), **Бас-лімітер** (`audio.bass_xo_hz`, типово 120 Гц,
0 — вимкнено), **Підйом біля порту** (`audio.port_lift_db`, типово 3 дБ, лише з портом). **Драйв**
(`audio.drive_db`) прибрано разом зі стелею (див. початок).
