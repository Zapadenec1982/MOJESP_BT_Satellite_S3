### Шрифти — гліфів уже досить

- **Повне покриття, крім двох знаків.** Сім текстових накреслень (16, 18, 18, 20, 24, 32,
  48 px) мають по 440 гліфів: ASCII, Latin-1, Latin Extended-A, кирилиця, типографська
  пунктуація. Кожен символ усіх чотирьох каталогів звірено з переліком гліфів кожного
  накреслення. Бракує лише двох: `→` (U+2192) і `≈` (U+2248). Вони стоять у трьох ключах
  калібрування (`cal.both_halves`, `cal.one_half`, `cal.c_measured`) — це сторінка лише
  вебу.
- **Великі літери з діакритикою влазять.** `Ś Ź Ż Ć Ń Ó Ä Ö Ü Ą Ę Ї Й Ґ` — у межах висоти
  рядка кожного накреслення: верх гліфа дорівнює висоті над базовою лінією, не виходить за
  неї.
- **`ẞ` (U+1E9E) немає, і він не потрібен:** німецькі великі пишуться через `SS`.
- **Годинник заставки** (160 px) — лише цифри й двокрапка. Дата — числова `ДД.ММ.РРРР`.
  Від мови не залежать.
- **Іконка `language`** (U+EA07) уже є в іконкових шрифтах.
- **У flash шрифти займають ≈ 660 КБ** (W6). U8 їх не змінює.

## 1. Принципи

1. **Одне джерело перекладів** — `webui/src/i18n/<lang>.json`. Ключ, який бачать і скло, і
   веб, має один текст. Окремих файлів перекладу панель не має.
2. **Текст складає екран.** Стан і модулі несуть коди або ключі каталогу, не речення. Це
   заразом лікує веб: статуси прошивки прийдуть мовою браузера.
3. **Таблиці — у flash.** Внутрішня RAM не росте: активна мова — один байт.
4. **Запасна мова — українська**, як у вебі. Ключа без тексту не буває — це стереже тест.
5. **Довжину перевіряє тест, а не око.** Око — на останньому кроці, на знімках.
6. **Без бібліотек.** Множина, підстановки й числа — близько сотні рядків C++ з host-тестами.

## 2. Що перекладати, а що ні

**Перекладається:**
- підписи екранів, оболонки, шухляди, діалогів, підписи клавіш;
- **Сервіс:**
  - підписи й причини перезапуску — ключі `svc.*` у вебі вже перекладені, тож це нічого не
    коштує;
  - абревіатури CPU, RAM, PSRAM, WDT, RTT, UART, `main` лишаються в рядках як є;
- **одиниці, що українською пишуться кирилицею:** мс, Гц, дБ, Б/КБ/МБ, д — ключі `unit.*`.
  Іншими мовами — ms, Hz, dB, KB;
- **назви з таблиць:**
  - схеми — `sys.scheme_*`;
  - пресети EQ — `eq.preset.<id>`;
  - країни — з CLDR;
  - жанри — у файлі жанрів (§9);
- **статуси модулів** — AirPlay, вимір порту, браузер DLNA, після переходу на ключі (U8.5).

**Не перекладається:**
- **журнал** (`ESP_LOG*`) — англійський і лишається таким, разом з українськими рядками
  журналу в ядрі (`persist_service.cpp`, правило 5);
- **усе з мережі й від людей:**
  - назви станцій, зокрема в пресетах;
  - ICY-назви, теги треків;
  - сервери й теки DLNA;
  - імена телефонів, SSID;
  - імена панелі в Bluetooth і AirPlay;
- **назви технологій і марок:** Wi-Fi, Bluetooth, AirPlay, DLNA, DSP, FLAC, AAC, LDAC, aptX,
  «P4 Player»;
- **стендові екрани** `m3test` і `scroll_bench`;
- **описи ключів у маніфестах** — довгий хвіст вебу має свій шлях
  (`modules/<m>/i18n/<lang>.json`, PLAN_WEBUI §3а) і в U8 не входить;
- **годинник і дата** — числові для всіх мов: `ЧЧ:ХХ`, `ДД.ММ.РРРР`.

## 3. Каталог і генератор

### Ключі

- **Ті самі файли й простори імен за функцією:** `wifi.`, `bt.`, `sys.`, `svc.`, `now.`,
  `cat.`, `st.`, `eq.`, `pair.`, `dlna.`, `lib.`, `unit.`.
- **Ключі лише для скла — у ті самі простори**, наприклад `wifi.err_wep`. Префікса `panel.`
  немає: коли ключ знадобиться вебу, перейменовувати нічого.
- **Коротка форма для скла — `<ключ>.short`**, і лише тоді, коли веб хоче довгу. Спершу
  пробуємо скоротити спільний текст: виграють обидва.
- **Множина** — `.one/.few/.many/.other`, усі чотири форми в кожному каталозі, як у вебі.
- **Цілі речення, не склейки.** `"%d %s на картці"` стає множинним ключем `lib.on_card`:
  «{n} трек на картці» / «{n} треки…» / «{n} треків…». Перекладачеві потрібне ціле речення.
- **Підстановки `{name}`**, як у вебі. Числа приходять уже відформатовані (§6).
- **Великі літери.** Заголовки груп Сервісу на склі капітеллю. Каталог тримає звичайний
  регістр, бо веб ставить капітель через CSS. Велику форму пише генератор (`str.upper()`
  Python: `ß` → `SS`, `ї` → `Ї`), тож рядкового перетворення регістру на пристрої немає.

### Генератор `tools/i18n/gen_panel_strings.py`

- **Вхід:**
  - чотири каталоги;
  - пошук у C++ (`modules/ui_lvgl/src` і модулі, що публікують ключі) таких посилань:
    `S::<id>` — рядок, `SU::<id>` — він же великими, `P::<id>` — множинний,
    `I18N_KEY("<ключ>")` — ключ, який модуль кладе в стан.
- **Ідентифікатор** = ключ із `.` → `_`: `wifi.forget_all` → `S::wifi_forget_all`.
  Генератор падає на збігу двох ключів в одне ім'я і на ключі, якого немає в каталозі.
- **Вихід** — закомічений, як шрифти, іконки й країни:
  - `modules/ui_lvgl/src/i18n/strings_gen.h` — `enum class S`, `SU`, `P`, `Lang`;
  - `strings_gen.cpp`: на кожну мову один `static const char[]` з рядків через `\0` і
    `static const uint16_t` зсуви. Окремо — відсортована таблиця ключів лише для
    `I18N_KEY`, щоб шукати за рядком із стану.
- **У flash — лише ключі, які використовує код:** ≈ 300 із 800+.

### API

```cpp
namespace i18n {
enum class Lang : uint8_t { UK, EN, DE, PL, COUNT };  // = ui.lang 0..3, порядок LANGS вебу
void        set_lang(Lang);                 // головна задача, під замком LVGL
Lang        lang();
const char* tr(S id);                       // ніколи не null; під кожною мовою — українська
const char* tr(SU id);
const char* plural(P id, int32_t n);        // правила CLDR, §6
const char* by_key(const char* key);        // ключ зі стану; невідомий → сам текст
size_t      fmt(char* out, size_t cap, const char* pattern,
                std::initializer_list<Arg> args);              // {name} → значення
const char* num(char* out, size_t cap, int32_t value10, int decimals);  // кома чи крапка
}
```

- **`fmt` обрізає по межі літери UTF-8**, ніколи всередині. Та сама біда, що в сесії «Fix
  Bluetooth track titles cut inside a UTF-8 letter»: якщо її помічник уже в `main`, беремо
  його.
- **Байти.** Буфери екранів розраховані на українську, де кирилиця — 2 байти на літеру.
  Латинка коротша в байтах: каталоги вебу важать uk 27 КБ, de 18, pl 17, en 16.
- **Мову пише лише головна задача, під замком LVGL**, а читає задача LVGL — один вирівняний
  байт.
- **Головна задача текстів не складає:** «Мережевий трек» у знімку стає прапорцем.

### Вартість

- **flash: ≈ +30 КБ нетто** з ≈ 836 КБ вільних:
  - рядки чотирма мовами ≈ 24 КБ, з них українські ≈ 9 КБ уже лежать в образі літералами;

- **Внутрішня RAM: 0.** Пастка — масив `const char* TABLE[]` без другого `const` лягає в

- **Бандл вебу.** Ключі лише для скла їдуть в `uk.json` усередині `bundle.js`: ≈ +4 КБ

  відкидатиме ключі, яких немає в `webui/src`. Це рішення сесії вебу.

## 4. `ui.lang`

- **У `modules/ui_lvgl/manifest.json` — як `ui.theme`:**
  - int 0–3, типово 0 — українська (рішення 2), readwrite, persist, mqtt_subscribe;
  - опис: «Мова панелі: 0 Українська, 1 English, 2 Deutsch, 3 Polski»;
  - порядок = `LANGS` вебу.
- **Число, а не рядок.** Жоден рядковий ключ у прошивці не зберігається. Шлях числа вже
  перевірений темою: хешований ключ NVS, `/api/settings`, MQTT.
- **Без віджета в розділі `ui` маніфесту**, як і `ui.theme`. Тому картки в довгому хвості
  немає, і `generate_ui.py` не міняється (правило 6).
- **На старті** мова читається до побудови екрана, поруч із темою
  (`ui_lvgl_module.cpp:168`).
- **Зміна не зі скла** — у ту саму перевірку двічі на секунду, що й тема
  (`ui_lvgl_module.cpp:448`).
- **Веб** (сесія вебу, U8.6):
  - мова браузера: явний вибір цього браузера → інакше `ui.lang` → інакше, поки немає
    зв'язку, мова браузера;
  - **пастка:** нинішній `stores/i18n.js` пише `modesp-lang` у localStorage на кожному старті,
    навіть без вибору. Кожен браузер, що хоч раз відкрив веб, уже «вибрав». Явний вибір
    потребує нового ключа (наприклад `modesp-lang-pick`), а старий ігнорується — інакше
    жоден із них не піде за панеллю;

### Як

- **Вибір.** Дотик до «Мова» відкриває діалог із чотирма рядками, кожна мова своєю назвою

  `apply_theme`; обидва зводяться в одну функцію перебудови.
- **Після перебудови:**
  - та сама сторінка;
  - правки EQ уже переживають перебудову (виправлено для теми, PLAN_REVIEW 1.12);
  - **перевірити:** діалог спарювання Bluetooth має повернутися зі стану `bt`;
  - **губляться:** набраний пароль Wi-Fi і рядок пошуку.
- **Мова змінена з вебу, коли на склі відкритий діалог або клавіатура.** Сьогодні тема
  поводиться так само. Пропоную відкладати перебудову (і мови, і теми) до їх закриття.
- **Тривалість перебудови** записати в журнал (мс) і в документ. Головна задача тримає
  замок LVGL увесь цей час. Після TWDT 12.10.2026 це не дрібниця. Якщо вийде понад
  100 мс — перенести перебудову в задачу LVGL (`lv_async_call`), тему разом із нею.

## 6. Множина, підстановки, числа

**Множина** — правила CLDR 48 для цілих:

| Мова | one | few | many |
|---|---|---|---|
| uk | n%10 = 1, n%100 ≠ 11 | n%10 ∈ 2…4, n%100 ∉ 12…14 | решта |
| pl | n = 1 | n%10 ∈ 2…4, n%100 ∉ 12…14 | решта |
| en, de | n = 1 | — | — (`other` — решта) |

- `other` в uk і pl — лише для дробів. Скло рахує цілі, але каталоги тримають усі чотири
  форми — правило вебу.
- Близько 15 рядків коду. Веб через `Intl.PluralRules` дає ті самі форми тих самих ключів.

**Інше:**
- **Підстановки** — `{name}` через `fmt`. Порядок слів — справа перекладу, а не аргументів
  `printf`.
- **Десятковий роздільник — за мовою**, як `Intl.NumberFormat` у вебі: uk, de, pl — кома,
  en — крапка (рішення 7). Сьогодні скло пише українською крапку («−3.5 дБ»): після U8 —
  «−3,5 дБ».
- **Лапки належать перекладу:** uk «…», de „…“, pl „…”. Гліфи є.

## 7. Довжина: як перевірити, що влазить

Інтерфейс 800×480 (альбомний, rotation 270), шрифти 16–48 px. Перевірка на трьох рівнях.

**1. Host, кожен коміт — `tools/i18n/fit.py`.**
- **Що міряє:** ширину кожного рядка скла кожною мовою за метриками самих накреслень, як у
  §0.
- **Правило без таблиці місць:**
  - переклад, не ширший за українську, влазить: українська вже стоїть на склі й прийнята;
  - ширший мусить бути в `modules/ui_lvgl/i18n_fit.json` — з шириною, підтвердженою на склі
    (рівні 2–3).
- **Коли падає:** рядок ширший за українську, а підтвердженої ширини немає або вона менша.
  Повідомлення каже, що робити.
- **Базу пише `fit.py --accept`** після перевірки на склі.

**2. Панель — один запит на мову: `GET /api/i18n/overflow`.** Лише читання, за логіном вебу.
- **Обхід дерева LVGL.** Сторінки побудовані всі одразу, сховані теж, тож перемикати їх не
  треба.
- **Звіт:**
  - написи, ширші за свою рамку: обрізані «…» або перенесені понад свою висоту;
  - написи з авто-шириною, що налізли на сусіда, наприклад заголовок на повзунок.
- **Для кожного:** сторінка, текст, шрифт, потрібно і є px.
- **Дозвіл.** Мову на панелі для цього перемикає `ui.lang` — лише з дозволу замовника.

**3. Знімки — `/api/screenshot?screen=<id>`.**
- **Скільки:** 11 сторінок і `peek=drawer|standby` × 4 мови, для ока й для замовника.
- **Дозвіл.** `screen=` перемикає сторінку панелі, а `ui.lang` — її мову. Лише з дозволу
  замовника, в узгоджений час, з логіном вебу.
- **Діалоги** (спарювання, «Забути…») відкриваються лише на стендовій збірці (`tap=`). Їх
  покривають рівні 1–2.

**Порядок виправлення:**
1. коротший спільний текст;
2. `.short` для скла;
3. зміна розкладки — в останню чергу.

LVGL переносить рядок лише на пробілах. Німецьке складне слово, довше за рамку, рветься
посеред слова — це ловить рівень 2.

## 11. Ризики

- **Якість перекладу.** de і pl у вебі зроблено без носія мови, скло додає ще ~130 рядків.
  Тест ловить пропуск, а не поганий переклад (питання 5, відкрите).
- **Довжина.** 89 зі 168 спільних ключів ширші за українські. Рівні §7 знайдуть усі; частина
  потребуватиме коротших форм, а місцями — правки розкладки (рядки Системи, кнопки
  діалогів).
- **Перебудова на головній задачі.** Тривалість невідома; історія TWDT від 12.10.2026 — §5.
- **Втрата стану при перебудові** — відкритий діалог чи клавіатура; відкладання з §5.
- **Два автори одних файлів.** Сесія вебу і U8 правлять ті самі чотири JSON — конфлікти
  злиття в плоскому файлі. Зливати часто; тест одного набору ключів ловить розбіжність.
- **Прошивка і веб разом.** Після U8.5 стан несе ключі:
  - новий застосунок зі старим вебом показує сирий ключ;
  - старий застосунок із новим вебом показує український текст як є, бо невідомий ключ —
    це сам текст;
  - тож шиються разом — застосунок і `data.bin`, як уже заведено.
- **RAM.** Один пропущений `const` кладе таблицю у внутрішню RAM. Перевірка `nm` і
  `idf.py size` — у DoD U8.1.
